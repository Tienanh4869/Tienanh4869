- **Công nghệ**: `Next.js 15`, `React 19`, `TypeScript`, `Tailwind CSS`, `Jotai`, `Zod`, `Resend`.
- **Điểm nổi bật**: Giao diện chuẩn UI/UX hiện đại, xử lý biểu mẫu nâng cao, quản lý state và tối ưu SEO / SSR.

- **Công nghệ**: `C# .NET`, `Windows Forms`, `Entity Framework Core`, `SQL Server`.
- **Kiến trúc**: Áp dụng **Clean Architecture** đa tầng (Domain, Application, Infrastructure, Presentation) và Repository Pattern giúp dễ bảo trì và mở rộng.

### 🧪 [Quản Lý Phòng Lab (Lab Management System)](https://github.com/Tienanh4869)
